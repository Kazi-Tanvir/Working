Based on the video, here are the 8 essential Markdown (.md) files every "vibe coder" or developer should set up before starting a project, especially when collaborating with AI tools:

1. PRD.md (Product Requirement Document)
This file sets the foundation of the project. It defines:

The problem statement you are solving.

Your target users.

Core features of the application.

Success criteria for the project.

2. TechSpec.md (Technical Specification)
This outlines your engineering choices and architectural decisions, including:

The chosen tech stack (frontend, backend, frameworks).

API designs and endpoints.

Authentication methods and databases to be used.

3. AppFlow.md
This maps out the user experience. It details:

The user journey from landing to exit.

The overall flow of the application.

What different screens and pages will exist.

4. Design.md
This acts as your design system blueprint, containing:

UI/UX guidelines and design language.

Color palettes (primary, secondary, background, etc.).

Typography and font choices.

5. Schema.md
This maps out your data architecture early on to avoid expensive changes later. It defines:

Database tables and collections.

Data types and how information is stored.

Relationships between different data models.

6. ImplementationPlan.md
This acts as your project roadmap. It breaks down the development lifecycle into distinct phases:

Discovery & Design

Development stages

Testing timelines

7. Tracker.md
A dynamic to-do list or task board. It's highly crucial for AI-assisted coding because your AI agent can read and modify this file to track what's To Do, In Progress, or Complete as it works.

8. Rules.md
This establishes the guardrails for your AI assistant. It specifies the strict rules the AI must follow while writing code (e.g., "Always use TypeScript strict mode," or "Favor functional components over classes"), ensuring the AI's output stays consistent and high quality.
